# QA Documentation

Test plans, QA sign-off records, and regression checklists.

## Structure

```
qa/
├── README.md
├── {{feature}}-test-plan.md     ← Generated by /gen-tests
├── {{feature}}-qa-signoff.md    ← QA sign-off record
└── regression-checklist.md      ← Ongoing regression scope
```

## Process

1. Run `/gen-tests` to generate test matrix for the feature
2. QA executes on staging environment
3. Record sign-off in `{{feature}}-qa-signoff.md`
4. Update regression checklist with new flows
