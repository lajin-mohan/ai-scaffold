# Estimates

Effort estimates for features, epics, and SOW preparation.

## Naming Convention

`{{TICKET-ID}}-{{feature-slug}}-estimate.md`

## Process

1. Run `/estimate "feature description"` or `/estimate docs/brd/feature.md`
2. Review assumptions and risk register with team lead
3. Get acceptance before sprint commitment
4. Update if scope changes significantly (>20% deviation)

## Template

`.claude/templates/estimation-template.md`

## SOW Estimates

For client-facing SOWs, use `.claude/templates/sow-template.md` which incorporates the estimate.
