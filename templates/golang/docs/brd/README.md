# Business Requirements Documents

Feature BRDs live here. One file per feature or epic.

## Naming Convention

`{{TICKET-ID}}-{{feature-slug}}-brd.md`

Example: `PROJ-001-user-management-brd.md`

## Process

1. Run `/create-brd "feature description"` to generate initial draft
2. Review and refine with stakeholders
3. Get approval before architecture work begins
4. Keep updated when requirements change — never work from stale BRDs

## Template

`.claude/templates/brd-template.md`
