# API Documentation

API contracts and reference documentation for all endpoints.

## Structure

```
api/
├── README.md
├── {{resource}}-contract.md   ← Generated by /create-api
└── {{resource}}-reference.md  ← Post-implementation reference doc
```

## Process

1. Run `/create-api "resource description"` to generate contract
2. Contract reviewed and approved before implementation
3. After implementation, generate reference docs via `@documentation-writer`
4. Keep contracts updated if API changes
